# Capsid v0.3.1-beta.1

Experimental `0.3.1-beta` release (runtime version `0.3.1`, public C ABI v7),
published as the default GitHub `Latest` release (`v0.3.1-beta.1`). The
maintained `0.2.x` stable line (`v0.2.2`) remains available by explicit tag.

## Changes

- Upgrades the embedded JavaScript engine from QuickJS-NG `0.15.1` to
  `quickjs-turbo` `v0.15.1-turbo.8` (`8fcb4751a66986bd42b11de3012e967d77790923`)
  via `patches/txiki/0079-quickjs-turbo-integration.patch` while keeping C ABI
  v7 and FetchRPC v3/v4 wire compatibility unchanged.
- Enables zero-JIT native register-frame interpreters on Linux x86_64/ARM64
  (glibc and static Alpine musl), macOS Intel x86_64 and Windows x86_64
  (portable C backend with Hybrid GC on Apple Silicon and sanitizers).
- Configures worker startup explicitly via `QJS_SetTurboDefaults`
  (`own_bytecode_tail = QJS_TURBO_OFF`, `property_ic = QJS_TURBO_ON`,
  `property_ic_warmup = 12`) plus a pre-`READY` `JS_PurgePropertyIC(rt)` pass
  so micro-container density and steady-state Property IC throughput coexist.
- Ships verified five-platform native archives for fully static musl Linux
  (x86_64/ARM64), macOS (Apple Silicon/Intel) and Windows (x86_64 MSVC/static CRT).

## Install

Install `v0.3.1-beta.1` on Linux or macOS:

```sh
curl -fsSL https://github.com/rowanellis-113/capsid/releases/download/v0.3.1-beta.1/install.sh \
  | CAPSID_REPO=rowanellis-113/capsid bash -s -- v0.3.1-beta.1
```

On Windows PowerShell (`x86_64`), verify the ZIP against its `.sha256` sidecar
and extract it into a clean directory. Do not mix the Host, worker, compiler or
SDK across builds; recompile trusted bytecode for the matching compatibility ID.
See the [installation guide](https://github.com/rowanellis-113/capsid/blob/dev/v0.3.1/docs/releases.md)
for OS/architecture selection and verification.

Linux strict sandboxing requires the documented kernel and delegation
prerequisites. Native macOS and Windows builds are for trusted development and
integration. The pinned compatibility profile retains five raw WPT file
failures; green CI is not full standards conformance. The accepted `v0.3.1-beta.1`
local WSL2 benchmark session (`6d4cc61`) precedes the Alpine musl build-script
and documentation commits in `845ae5d` and does not measure the distributed
release archives directly.
